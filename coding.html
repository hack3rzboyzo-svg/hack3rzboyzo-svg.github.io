imageditor.py
Dataset Image Augmentor — generates hundreds of augmented training images from a single source. Applies random combinations of 17 augmentations including blur, noise, perspective warp, sepia, and more.
Pillow NumPy 17 augmentations CLI args JPEG / PNG / WEBP
1
Install dependencies
pip install Pillow numpy
2
Navigate to the script folder
cd C:\Users\YourName\Downloads
Replace with wherever you saved the file.
3
Basic run — just point at an image
python imageditor.py --input photo.jpg
Generates 300 images into ./augmented_dataset by default. The image must be in the same folder as the script, or use a full path.
4
Full command with all options
python imageditor.py --input photo.jpg --output ./my_dataset --count 500 --format JPEG --quality 90
